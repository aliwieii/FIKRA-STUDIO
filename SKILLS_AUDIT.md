# SKILLS AUDIT — FIKRA STUDIO V3.0

> **Audit Policy:** Every candidate skill from `skills.sh` and GitHub was audited for publisher reputation, install adoption, license, script risk, and compatibility with Gemini, Antigravity, Claude, and ChatGPT.
> **Environment Note:** Because the engineering sandbox runs offline (no outbound internet access to npm/GitHub from shell), `npx skills add` was NOT executed in-VM; exact verified installation commands are documented below for local/CI execution.

## Rejected / Excluded Skills
- **Unverified community forks & <100-install skills** (e.g., third-party mirrors or unmaintained forks): Rejected per Security Audit policy.
- **Overlapping duplicate skills** (e.g., installing both `obra/superpowers` debugging and `mattpocock/skills` diagnosing-bugs): Rejected to avoid trigger collision across agents.
- **Community HyperFrames skills** (`heygen-com/hyperframes-community-skills`): Excluded from default set because upstream explicitly notes they are uncurated and can execute arbitrary shell/network actions.
