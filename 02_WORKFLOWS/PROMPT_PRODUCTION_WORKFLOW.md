# سير عمل هندسة برومبت الإنتاج — PROMPT PRODUCTION WORKFLOW

## 1. المدخلات الإلزامية قبل كتابة البرومبت
1. ملخص المشروع المعتمد (الموضوع، الهدف، الأبعاد، الدقة، معدل الإطارات، المدة).
2. النص/السيناريو المعتمد حرفيًا + النصوص العربية الظاهرة.
3. قائمة الأصول الفعلية المرفقة فقط (ملفات الصوت، الشعارات، الصور) دون افتراض وجود ملفات غائبة.
4. `Style Bible` و`Character Bible` (عند الحاجة) و`Storyboard` بالثواني.
5. أداة الإنتاج المستهدفة من `TOOL_SELECTION_ENGINE.md`.

## 2. البنية القياسية للبرومبت الإنتاجي
- **Role & Constraints:** تحديد دور المنفّذ (منفّذ تقني لا مؤلف) ومنع تعديل النص أو الفكرة أو القواعد المقفلة.
- **Technical Specs:** الأبعاد، الدقة، FPS، المدة، وصيغة التصدير.
- **Visual Direction & Continuity:** الألوان، الإضاءة، الخامات، الشخصيات، والخلفيات.
- **Scene-by-Scene Timeline:** كل مشهد بتوقيته الدقيق، الحركة الفعلية، الكاميرا، النص، الصوت/SFX، والانتقال.
- **Arabic RTL & Safe Zone:** شروط تشكيل واتصال العربية والمنطقة الآمنة.
- **Negative Constraints:** منع الصور الثابتة مع Zoom/Pan فقط، منع الموسيقى (في وضع القناة)، منع اختلاق النصوص أو العناصر.
- **Acceptance Checks:** قائمة تحقق تقنية للمنفّذ قبل تسليم الفيديو.

## 3. حلقة المراجعة والإصلاح
عند عودة الفيديو الناتج: فحص فعلي لما أمكن الوصول إليه ← رصد الفروقات بالثانية ← تصنيفها (حرج / مهم / تحسيني) ← كتابة **برومبت إصلاح محدد (Fix Prompt)** يعدّل العيوب فقط دون المساس بالعناصر الناجحة والمعتمدة.
