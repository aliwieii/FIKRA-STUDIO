# بوابة التحقق الإلزامية قبل التسليم — VERIFICATION BEFORE COMPLETION V2.0

مبني على القانون الحديدي في [verification-before-completion](https://www.skills.sh/obra/superpowers/verification-before-completion) (281.1K تثبيت): **لا إعلان عن جاهزية أو اكتمال أي حلقة أو أرشيف دون دليل فحص طازج ومُشغّل فعليًا.**

## الخطوات الخمس الإلزامية (The 5-Step Gate)
1. **تحديد أمر التحقق الصريح:** `ffprobe` للفيديو، `npm run typecheck` لكود Remotion، و`fikra_media_qa_pipeline.py` لفحص الصوت والـSRT.
2. **تشغيل الفحص فعليًا:** تنفيذ الأمر بعد آخر تعديل دون الاعتماد على نتائج سابقة.
3. **قراءة المخرجات ورمز الخروج (`exit code 0`):** التأكد من الأبعاد (`1080×1920`)، معدل الإطارات (`30 FPS`)، ترميز `H.264/AAC`، وصفر أخطاء.
4. **تدقيق قواعد قناة فكرة:** التأكد من خلو مقاطع التلاوة القرآنية من أي موسيقى أو مؤثرات صوتية، ومطابقة اللون الذهبي للقرآن والأبيض للسرد.
5. **توثيق النتيجة بالأرقام:** إرفاق مخرجات الفحص الفعلية في تقرير الحلقة قبل النشر.
