# قالب حزمة الصوت للوضع العام — UNIVERSAL VOICE PROMPT

## 1. شخصية الصوت والأداء (Style Prompt)
- **الجنس والعمر والطبقة:** `[مثال: صوت شاب حيوي / صوت نسائي دافئ / صوت وثائقي عميق]`
- **اللغة واللهجة:** `[عربية فصحى / لهجة محلية / إنجليزية]`
- **النبرة والسرعة والانفعالات:** `[حماسي / تعليمي هادئ / ساخر / درامي]`
- **التوقفات وملاحظات النطق:** `[توقف 0.5 ثانية قبل الرقم الرئيسي...]`

## 2. النص المنطوق النظيف (Voiceover Text)

[النص الذي سيُقرأ فقط دون تعليمات.]
