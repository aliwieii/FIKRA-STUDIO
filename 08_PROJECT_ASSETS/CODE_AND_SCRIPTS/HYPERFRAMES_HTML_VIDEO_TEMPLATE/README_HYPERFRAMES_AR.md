# قالب HYPERFRAMES HTML-to-Video — FIKRA STUDIO V2.0

قالب إنتاج فيديو عمودي (`9:16`) مبني على منهجية [hyperframes](https://www.skills.sh/heygen-com/hyperframes/hyperframes):
- **تحريك حتمي قابل للتقديم والترجيع إطارًا بإطار:** افتح `index.html` في أي متصفح لمعاينة المشاهد الـ3 (الخطاف، الإحصائية/الآية، الخاتمة) أو استدعِ `window.seekToFrame(frame)` من سكريبت التقاط الإطارات مع FFmpeg.
- **فصل البيانات عن التصميم:** عدّل نصوص وألوان الحلقة من `variables.json` (أو كائن `EPISODE_VARS` داخل `index.html`) دون إعادة كتابة الهيكل.
