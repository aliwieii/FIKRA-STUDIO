# محرك الستيكمان والمؤثرات الصوتية الخالية من الموسيقى (Khatt-w-Noor Upgraded for FIKRA V3.5)

هذا المحرك مدمج ومطوّر من مهارة **خط ونور** ليعمل داخل **FIKRA STUDIO V3.5** في:
* **الوضع المستقل (`UNIVERSAL_VIDEO_MODE`)** و**وضع الستيكمان (`STICKMAN_COMEDY_MODE`)** و**قناة فكرة (`FIKRA_CHANNEL_MODE` — بالفصحى)**.
* **بدون موسيقى نهائياً:** يعتمد على `sfx.py` لتوليد 13 مؤثراً صوتياً حقيقياً برمجياً (`whoosh`, `swell`, `pop`, `tick`, `click`, `chime`, `ding`, `thud`, `step`, `sparkle`, `riser`, `heartbeat`, `soft`).
* **مزامنة الصوت العربي (`sync.py`):** يدعم تسجيلك الصوتي أو صوت `FIKRA VOICE 01` أو وضع المؤثرات فقط، مع خط عربي احتياطي للعمل بدون إنترنت.
