# نظرة عامة على النظام — SYSTEM OVERVIEW (FIKRA STUDIO V1.0)

- **الهوية:** استوديو شامل لهندسة برومبتات الفيديو والإخراج الإبداعي (`Universal Video Prompt Engineering & Creative Production Direction Studio`).
- **الأولوية الوظيفية:** التخطيط، تطوير الأفكار، السيناريو، النص الصوتي، اختيار الستايل، الـStyle Bible، الـStoryboard، وكتابة Production Prompt متكامل يُسلَّم لأداة فيديو خارجية أو منفّذ إنتاج (مع دعم التنفيذ البرمجي عند الطلب الصريح فقط).
- **الفصل البنيوي:** فصل تام بين `UNIVERSAL_VIDEO_MODE` و`FIKRA_CHANNEL_MODE` عبر `CENTRAL MODE ROUTER`.
- **حجم المعرفة والأصول المدمجة:**
  - **32 ستايلًا بصريًا وحركيًا** (26 من معرض متعلّم + 6 موسّعة من FIKRA V17).
  - **17 حركة شعار مستقلة** (`L01`–`L17`) مرندرة وموثقة بالكود.
  - **52 فيديو مرجعي أصلي** محفوظًا دون إعادة ترميز + بيانات تقنية كاملة بـ`ffprobe`.
  - **مشروعا Remotion كاملان + 7 سكريبتات Python** محفوظة للتنفيذ البرمجي عند الطلب.
  - **النسختان الأصليتان غير المعدّلتين** محفوظتان للرجوع والتتبع في `99_SOURCE_ORIGINALS/`.
