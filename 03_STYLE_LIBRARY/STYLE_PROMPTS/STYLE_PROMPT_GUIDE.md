# دليل تحويل الستايل إلى برومبت إنتاجي

عند اختيار أي ستايل من `03_STYLE_LIBRARY/STYLE_INDEX.md`:
1. افتح ملف مواصفاته في `STYLE_SPECIFICATIONS/STY-XXX_*.md`.
2. إن كان للستايل فيديو مرجعي في `07_REFERENCE_MEDIA/VIDEOS/`، ارجع إلى بطاقة تحليله أو حلّله إن كانت الأدوات متاحة.
3. انقل المبادئ التالية إلى برومبت الإنتاج دون نسخ محتوى المرجع:
   - **لوحة الألوان الدقيقة (Hex) ونظام الخلفية.**
   - **لغة الحركة (Easing / Spring / Stepped / Draw-on).**
   - **حركة الكاميرا والعمق.**
   - **توقيت ظهور النصوص العربية واتجاه RTL.**
   - **طبيعة المؤثرات الصوتية المتزامنة مع الحركة.**
4. يمكن دمج ستايلين أو ثلاثة بوضوح (مثال: `STY-011 Infographic` + `STY-001 Kinetic Typography`) بشرط وحدة لوحة الألوان والإيقاع.
