# STY-018 — حركة الواجهات وإطلاق المنتجات (UI Animation / Product Promo)

## 1. بطاقة التعريف
- **Style ID:** `STY-018`
- **الاسم الأصلي:** حركة الواجهات وإطلاق المنتجات / UI Animation / Product Promo
- **الفئة:** المنتجات والتطبيقات (Product & UI)
- **المصدر:** Motalim Motion Starter Kit (gallery + styles/)
- **حالة الجاهزية (`Readiness Status`):** `SPEC_READY`
- **الصعوبة البرمجية:** سهل بالكود
- **الاستخدامات المناسبة:** إعلان تطبيق، أو موقع، أو منصة، أو شرح تقني
- **كلمات البحث المرجعية (Pinterest):** `app ui animation`

## 2. الهوية البصرية واللونية والإضاءة
- **Visual Identity & Mood:** أسلوب حركة الواجهات وإطلاق المنتجات (UI Animation / Product Promo) مصمم لتقديم إعلان تطبيق، أو موقع، أو منصة، أو شرح تقني بوضوح بصري عالٍ وحركة فعلية تخدم المعنى.
- **Color Palette (مستخلصة من المعرض/المرجع):** `#000, #fff`
- **Lighting & Materials:** إضاءة متسقة مع طبيعة الأسلوب (مسطحة نظيفة للـ2D والواجهات، أو اتجاهية ناعمة للعمق والـ3D) وخامات غير مشتتة للنص.
- **Background:** خلفية منضبطة التباين تضمن قراءة النص العربي داخل المنطقة الآمنة (Safe Zone).

## 3. التكوين والكاميرا ولغة الحركة
- **Composition:** توازن بصري واضح مع تركيز على عنصر بؤري واحد في كل لحظة سردية.
- **Camera Language:** انتقالات مدروسة (Pan/Zoom وظيفي، تتبّع رسم، أو انتقالات بلا قطع حسب الأسلوب) دون اهتزاز عشوائي.
- **Animation Language & Motion Behavior:** منحنيات الحركة المرصودة: `back.out(1.6), none, power3.out`. يعتمد على التحويلات المكانية والظهور التدريجي والطبقات. يدعم عدّادات الأرقام المتحركة المتزامنة.
- **Transitions:** انتقالات نابعة من منطق المشهد (Morph / Wipe / Camera Travel / Hard Cut) بدل المؤثرات الزخرفية المكررة.
- **Typography (Arabic RTL):** خطوط عربية واضحة (`IBM Plex Sans Arabic` / `Cairo` / `Tajawal`)، اتجاه `RTL` سليم دون تفكيك الحروف.
- **Character Design & Scene Construction:** يُفعّل `Character Bible` عند وجود شخصية متكررة لضمان ثبات النسب والملامح والملابس عبر المشاهد.

## 4. التوجيه الصوتي ومتطلبات الإنتاج
- **Sound Direction:** مؤثرات صوتية متزامنة مع الأفعال البصرية (حركة، ظهور نص، انتقال)؛ وفي وضع قناة FIKRA تُطبَّق سياسة حظر الموسيقى التام.
- **Suitable Engines:** Remotion (React + TS + SVG/Canvas) للستايلات السهلة والمتوسطة؛ Three.js أو Blender للمشاهد ثلاثية الأبعاد المعقدة.
- **Technical Limitations:** تجنّب تحويل الأسلوب إلى صور ثابتة مع Zoom/Pan فقط؛ والتحقق من تشكيل العربية قبل الرندر.
- **Quality Checklist:** [ ] حركة فعلية في كل مشهد | [ ] عربية RTL سليمة | [ ] تباين لوني ≥ 4.5:1 | [ ] مزامنة دقيقة مع الصوت | [ ] لا نسخ من محتوى المرجع.

## 5. المراجع والأصول المرتبطة

## كيف بُني (للوكيل)

### النصوص
- **سطر الكلمات:**
  - الكلمة الأولى تدخل بشفافية و`blur` يقل وتصغير خفيف.
  - ثم يتحرك حجم الخط من الكبير إلى الصغير، والكلمات التالية تدخل بتأخير متدرج.
  - الخروج بـ `blur` وإزاحة جانبية.
- **النص المتدرج:**
  - `background-clip: text` مع حشوة وهامش سالب بنفس القيمة.
  - الحشوة تكبّر صندوق الخلفية فلا تُقص نقاط الياء والحروف النازلة.

### الخلفية والإطار
- **التوهج:** كل بقعة `radial-gradient(closest-side, …)` تصل للشفافية عند حافة صندوقها بالضبط، فلا تظهر لها حواف.
- **خانة الطلب:**
  - مستطيل SVG بـ `pathLength={1}` و`strokeDasharray` للرسم، وشرطة بيضاء قصيرة تمشي أمامه كرأس الضوء.
  - نسخة من الحافة بعرض أكبر وتمويه للتوهج.
  - الزووم بـ `transform-origin` عند أول السطر، ويرجع للخلف مع الكتابة.
- **اللوجو:** الاسم داخل حاوية `maxWidth` تكبر مع `overflow: hidden`، فيدفع الأيقونة جانبًا وهو ينفتح.

### العمق
- **النافذة:**
  - CSS `perspective` مع `rotateX` و`rotateY` و`translateZ`.
  - مفاتيح كاميرا تُدمج بإيزينج ناعم.
  - خلف النافذة طبقة بتدرج ألوان وظلال متوهجة، فتبدو الحافة نيونًا.
- **الكروت:**
  - كل كارت له `translateZ` ثابت، والكاميرا تتقدم بقيمة واحدة تُضاف للكل.
  - الكارت يختفي وهو يعبر بجانب الكاميرا.
  - صوت العبور يُحسب من نفس المعادلة (عكس الإيزينج)، فيأتي في لحظة العبور.

### الكورة
- **الكلمات البيضاء فوق الكورة:**
  - صف الكلمات يُرسم مرتين: نسخة غامقة، ونسخة بيضاء مقصوصة بـ `clip-path: circle()` على مكان الكورة.
  - فتصير الكلمة بيضاء داخل الكورة فقط، حتى لو كان نصفها داخلها.
- **الحلقات:** كبسولات بنفس المركز، يكبر عرضها وارتفاعها مع كل خطوة.
- **الكبسولة:** الكلمات تتدحرج رأسيًا داخل كبسولة `overflow: hidden`.

### الصوت
- لكل ملف صوت وقت قمته بداخله (جدول `PEAK`).
- يبدأ الصوت قبل الحدث بنفس المقدار، فتقع القمة على اللحظة بالضبط.
- والصعود يُضبط على لحظة نهايته.
